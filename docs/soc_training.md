# Дообучение VE-моста с Adjoint Matching

Установите проект с поддержкой чтения JPEG-коэффициентов.

```bash
python -m pip install -e '.[soc-jpeg,eval,quality]'
```

Для локального запуска с PSNR достаточно extra `soc-jpeg`. Профиль CelebA использует дополнительные модели и их веса. Подготовка ArcFace, LPIPS, MUSIQ и Inception описана в [документации базового моста](main_training.md).

В [примере конфига](../configs/soc/train.yaml) укажите путь к доверенному чекпойнту BM/ABM. Архитектура, параметры моста, препроцессинг, JPEG-настройки и разбиение берутся из чекпойнта. Относительные пути отсчитываются от рабочего каталога. Выберите `training.device: cpu` для короткой локальной проверки. Параметры примера служат начальной настройкой, beta подбирается на валидации.

```bash
bridge-soc-train --config configs/soc/train.yaml
```

- `control.teacher_weights` выбирает EMA или raw. `control.mode` определяет режим ученика. Если режим опущен, он наследуется от учителя.
- `reward.input` выбирает изображение для награды. `clipped` применяет ограничение диапазона внутри терминальной стоимости. `raw` сохраняет значения за пределами диапазона и соответствующие градиенты.
- `sampling.clip_output` управляет ограничением выдаваемого изображения. Валидация использует настройку награды и сравнивает учителя с учеником на одинаковых наблюдениях и шумах.
- `sampling.num_steps` и `sampling.start_offset` можно переопределить в YAML. По умолчанию они берутся из чекпойнта учителя.

JPEG-награда возвращает минус сумму квадратов расстояний до интервалов квантования. Индексы и таблицы извлекаются через `jpeglib` из тех же байтов Pillow, из которых получено наблюдение. Награда использует непрерывную RGB → YCbCr → DCT модель с усреднением chroma и репликацией границ. Шкала согласована с коэффициентами потока. Из-за округления цвета и целочисленных операций кодека штраф на породившем JPEG изображении может быть ненулевым. При локальной проверке четырёх синтетических RGB-изображений 17×19 на Pillow с quality=10 и 4:2:0 значения штрафа составили 0.000, 0.092, 0.475 и 0.491 в единицах суммы квадратов DCT-коэффициентов.

## Расписание и выбор модели

Одно обновление Adam использует до `grad_accum_steps` микробатчей. По умолчанию `batch_size: 1` и `grad_accum_steps: 1`. При `max_steps: null` запуск обрабатывает один полный проход по train. Целое значение ограничивает число обновлений. Короткий smoke-запуск можно провести на CPU с малым `max_steps`, меньшим числом шагов sampler и лёгкими метриками.

Полная валидация запускается каждые `training.validation_interval` обновлений и на финальном шаге. SOC наследует из чекпойнта учителя размеры фиксированных выборок, наборы метрик, baseline и визуальные ID. Поля секции `evaluation` переопределяют эти настройки. Например, для smoke-запуска можно явно задать небольшие `subset_size` и `test_subset_size`, `metrics: {psnr: {}}`, `test_metrics: {psnr: {}}` и null для обоих путей визуальных списков. Размер null выбирает полный сплит. Для стандартного CelebA-профиля используется 512 изображений на val и 1024 или 4096 на test, в зависимости от эксперимента учителя.

Чекпоинт с максимальной средней JPEG-наградой на val оценивается на отдельном test после обучения. При равных значениях остаётся более ранний чекпоинт. Оба отчёта используют raw-веса ученика и сохраняют обычные метрики восстановления, награду и фиксированные панели.

```text
runs/soc/jpeg/
  config.yaml
  split.json
  metrics.jsonl
  checkpoints/last.pt
  validation/step_00000100/{summary.json,per_image.jsonl,protocol.json,images/}
  best/reward/{checkpoint.pt,summary.json,per_image.jsonl,protocol.json,images/}
  test/reward/{summary.json,per_image.jsonl,protocol.json,images/}
```

`last.pt` записывается на интервале чекпоинтов и после каждой завершённой валидации. Для продолжения используйте этот файл и при необходимости увеличьте `training.max_steps` в YAML. При переходе со старого SOC-конфига замените `training.validation_batches` на `evaluation.subset_size` в изображениях. При загрузке старого `last.pt` новый протокол сначала оценивает восстановленные веса на val и начинает историю отбора с этой оценки.

```bash
bridge-soc-train --config configs/soc/train.yaml --resume runs/soc/jpeg/checkpoints/last.pt
```

Для инференса загрузите ученика и сохранённые настройки сэмплера. `observation` имеет форму `[B, 3, H, W]`, нормирована в `[-1, 1]` и подготовлена так же, как при обучении.

```python
import torch
from bridge_soc.checkpoint import load_student

student, sampler = load_student("runs/soc/jpeg/checkpoints/last.pt", device="cpu")
generator = torch.Generator().manual_seed(42)
result = sampler.sample(student, observation, generator)
reconstruction = result.reconstruction
```

SOC-сэмплер завершает траекторию детерминированным шагом Эйлера до нуля. Прежний `bridge-sample` для BM/ABM продолжает возвращать финальное предсказание денойзера.
